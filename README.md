# O AdoteAqui é uma plataforma que facilita a adoção de animais, conectando adotantes a cães e gatos que precisam de um lar
Permitindo buscar animais por categoria e visualizar suas informações
O usuário cadastra nome e e-mail e pode comentar o motivo pelo qual deseja adotar.
O objetivo é tornar a adoção mais simples e acessível.
